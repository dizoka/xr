CRYSTALSTOREBOT — БЕЗПЕЧНЕ ОНОВЛЕННЯ БЕЗ РУЧНИХ ЗМІН TURSO
================================================================

ЩО ПОТРІБНО ЗРОБИТИ

1. Розпакуйте повний архів.
2. Завантажте ВЕСЬ вміст у корінь вашого GitHub-репозиторію з заміною старих файлів.
3. Натисніть Commit changes.
4. Render автоматично почне Deploy. Якщо ні:
   Manual Deploy -> Clear build cache & deploy.
5. Змінні Environment у Render НЕ змінюйте.
6. У Turso вручну нічого створювати й змінювати НЕ потрібно.

Під час першого запуску бот сам:
- додасть відсутні службові колонки;
- створить таблицю для збереження FSM-станів;
- збереже старі товари, категорії, заявки й адміністраторів;
- визначить для старих POD-систем параметр «Колір»;
- визначить для старих рідин параметр «Смак».

ОСНОВНІ ПОКРАЩЕННЯ

- FSM тепер зберігається у Turso, тому введення кольору/смаку не губиться після перезапуску Render.
- Доданий глобальний захист від необроблених помилок.
- Доданий захист від флуду для покупців та адміністраторів.
- Доданий /help.
- Замовлення створюються через окремий OrderService.
- Повідомлення продавцям надсилаються паралельно й не падають, якщо хтось заблокував бота.
- Захист від подвійного натискання «Обрати товар».
- Старе замовлення зберігає назву й ціну товару на момент оформлення.
- Видалення товару/категорії стало м’яким: старі заявки не зникають.
- При додаванні товару можна вибрати: Колір / Смак / Інший варіант / Не запитувати.
- Для старих POD-систем і рідин тип визначається автоматично.
- Налаштування магазину кешуються, щоб зменшити кількість запитів до Turso.
- Картки товарів і замовлень стали читабельнішими.
- На картці товару є кнопка «Написати продавцю».
- Пошук показує індикатор «бот друкує».
- Додані health-check адреси:
  /               — легка перевірка, найкраще для UptimeRobot;
  /health/live    — процес працює;
  /health         — процес і Turso працюють;
  /health/ready   — процес і Turso працюють.

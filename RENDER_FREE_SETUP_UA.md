# CrystalStoreBot — безкоштовний запуск на Render

Ця версія використовує:

- **Render Free Web Service** для роботи Telegram webhook;
- **Turso Free** для постійного збереження категорій, товарів і заявок;
- жодного платного диска або Background Worker.

## Важливе обмеження безкоштовного Render

Після 15 хвилин без вхідних запитів сервіс засинає. Коли користувач знову напише боту, Telegram webhook розбудить його. Перша відповідь після сну іноді займає близько хвилини. Наступні відповіді працюють швидко.

## 1. Створення безкоштовної бази Turso

1. Відкрийте сайт Turso та створіть безкоштовний акаунт.
2. Створіть нову базу, наприклад `crystalstore`.
3. Скопіюйте **Database URL**. Він виглядає приблизно так:

```text
libsql://crystalstore-назваакаунта.turso.io
```

4. Створіть токен бази та скопіюйте **Auth Token**.

Збережіть обидва значення — вони знадобляться на Render.

## 2. Завантаження на GitHub

1. Створіть приватний репозиторій GitHub, наприклад `crystalstore-bot`.
2. Розпакуйте цей архів.
3. Завантажте **вміст папки `CrystalStoreBot_Render_FREE`** у корінь репозиторію.
4. Файл `.env` із токенами на GitHub не завантажуйте.

У корені мають бути:

```text
main.py
render.yaml
requirements.txt
bot/
```

## 3. Безкоштовний деплой на Render

1. У Render натисніть **New → Blueprint**.
2. Підключіть GitHub і виберіть репозиторій.
3. Render знайде `render.yaml` та створить **Free Web Service**.
4. Введіть змінні:

### BOT_TOKEN

Токен Telegram-бота від BotFather.

### ADMIN_IDS

Ваш числовий Telegram ID. Для кількох адміністраторів використовуйте кому:

```text
123456789,987654321
```

### TURSO_DATABASE_URL

Адреса бази Turso:

```text
libsql://crystalstore-назваакаунта.turso.io
```

### TURSO_AUTH_TOKEN

Токен доступу до бази Turso.

`WEBHOOK_SECRET (необов’язково)` додавати не потрібно — бот сам створює безпечний секрет.

5. Натисніть **Apply** або **Deploy Blueprint**.
6. Дочекайтеся повідомлення в Logs:

```text
Бот CrystalStore запущено безкоштовно на Render
```

## 4. Перевірка

У Telegram надішліть боту:

```text
/start
```

Адміністратор може відкрити:

```text
/admin
```

## Якщо бот довго не відповідає

Після 15 хвилин тиші безкоштовний Render засинає. Надішліть `/start` ще раз через 30–60 секунд. Дані товарів не зникнуть, бо вони зберігаються в Turso, а не на локальному диску Render.

## Не запускайте дві копії одночасно

Коли версія на Render працює, закрийте локальний `START.bat`. Для одного токена Telegram повинен використовуватися один активний спосіб отримання оновлень.

ОНОВЛЕННЯ CRYSTALSTORE BOT

1. ОФОРМЛЕННЯ ТОВАРУ
- Покупець відкриває товар і натискає «🛒 Обрати товар».
- Для рідин бот просить написати смак.
- Для POD-систем бот просить написати колір.
- Для інших категорій бот просить потрібний варіант.
- Далі покупець може додати коментар або натиснути «Без коментаря».
- Повна заявка надходить лише власникам із ADMIN_IDS.

2. ОБМЕЖЕНА АДМІНКА ДЛЯ ПРАЦІВНИКА
Спочатку людина надсилає боту команду /id і передає вам свій Telegram ID.

Видати доступ:
/addadmin 123456789

Забрати доступ:
/deladmin 123456789

Переглянути список:
/admins

Працівник відкриває /admin і може змінювати тільки:
- ціну;
- кількість;
- наявність.

Категорії, опис, фото, назву, налаштування, акції, видалення товарів та запити працівник змінювати не може.

3. ОНОВЛЕННЯ НА GITHUB
Замініть весь код у репозиторії файлами з цього архіву.
Після Commit changes на Render виконайте:
Manual Deploy -> Clear build cache & deploy.

База Turso оновиться автоматично. Старі товари не видаляться.
